# hannibalautos.fr

Site du garage Hannibal Autos (PHOENIXAUTO SAS), Maisse (91).

- `index.html` : la page du site
- `voitures.js` : **la liste des voitures** (le seul fichier à modifier pour ajouter, changer ou retirer une voiture)
- `img/` : photos, logos, icônes ; mettre les photos des voitures dans `img/voitures/`
- `mentions-legales.html` : mentions légales

Hébergé gratuitement avec GitHub Pages.
